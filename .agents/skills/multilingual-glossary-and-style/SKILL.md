# Multilingual Glossary & Style Control

## Objective
Keep terminology consistent across multiple images and multiple target languages.

## Priority order
1. User-provided explicit wording
2. User-provided glossary
3. Product/brand terminology
4. Established domain terminology
5. Natural target-language translation

## Protect
Do not translate brand names, product names, model numbers or proprietary terms unless explicitly instructed.

## Consistency
Use the same translation for repeated source terms within the same localization project unless context requires a different grammatical form.

## Multiple languages
Maintain independent terminology per target language.

Example:
BOOSTER
- Japanese: ブースター
- Hindi: बूस्टर
- German: Booster
- French: Booster
- Spanish: Potenciador

The exact translation must be selected based on context, not blindly from this example.

## User override
If the user says:
"Translate BOOSTER as X"
then X is authoritative for that project.
