# Antigravity Multilingual Image Localization Skills

Copy the `.agents/skills/` structure into your Antigravity workspace.

Recommended skill set:
- multilingual-image-localization
- multilingual-ocr-text-detection
- multilingual-translation
- typography-and-effects-preservation
- localization-qa
- multilingual-glossary-and-style

For a simple setup, start with `multilingual-image-localization` and add the others as specialized skills.

Example user request:
Target language: Japanese
Localize all translatable text in the uploaded image.
Preserve the original artwork, typography, effects, layout and transparency.

For multiple outputs:
Target languages: Japanese, Hindi, German, French, Spanish
Create one localized image per language.
