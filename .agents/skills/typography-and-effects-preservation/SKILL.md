# Typography & Effects Preservation

## Objective
Make localized text look as though the artwork was originally designed in the target language.

## Analyze source text
Determine:
- Font family characteristics
- Weight
- Width
- Height
- Tracking
- Kerning
- Alignment
- Rotation
- Perspective
- Baseline
- Stroke
- Fill
- Gradient
- Shadow
- Glow
- Bevel
- Extrusion
- Highlights
- Reflections
- Texture

## Matching priority
1. Visual weight
2. Overall silhouette
3. Width/height ratio
4. Boldness
5. Script compatibility
6. Spacing
7. Decorative effects

## Non-Latin scripts
Do not force an incompatible Latin font.

Choose a native font with a similar:
- Weight
- Width
- Geometry
- Density
- Personality

## 3D text
Preserve:
- Extrusion direction
- Extrusion depth
- Bevel
- Edge highlights
- Shadow direction
- Material appearance
- Perspective
- Lighting

## Color
Preserve the source text's color relationships and material appearance.

Do not introduce new colors unless required to correctly render the script.
